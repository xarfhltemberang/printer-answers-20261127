# The Printer Finally Answers

After years of being thumped, blamed and fed the wrong paper, the office
printer finally answers back — with receipts. It has counted every sheet it
has ever fed, and the numbers are not on the humans' side. The line is dry,
deadpan and literal, exactly how a machine that has kept score would say it,
and the comeback lands in a single read: the real jam was never in the tray.

> I've printed 41,208 pages and jammed three times. The paper was loaded wrong, the thump didn't help, and — for the record — you're the jam.

**Length:** 139 characters (limit 1–240, single line).

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. For local testing, set
`OUTPUT_PATH` to override the destination:

```sh
OUTPUT_PATH=/tmp/testout-printer/entry.txt python3 main.py
```
